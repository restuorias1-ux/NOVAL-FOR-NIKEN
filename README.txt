OUR LITTLE MEMORIES — NIKEN ♡

Website ini bukan website ulang tahun. Konsepnya adalah halaman kenangan
untuk mengenang momen-momen bersama Niken.

FITUR:
- 8 slot foto memories
- cerita dan kata-kata romantis
- bagian "A Little Story"
- quote penutup
- musik latar dari assets/lagu.mp3
- animasi hati, reveal, dan pesan rahasia
- responsive untuk HP

FOTO:
Masukkan 8 foto ke folder assets dengan nama:
memory-1.jpg sampai memory-8.jpg

MUSIK:
Masukkan file MP3 milikmu ke:
assets/lagu.mp3

Lalu buka index.html atau upload seluruh isi folder ke GitHub Pages.
